# Contributing

Thanks for contributing!

1. Install the .NET 10 SDK.
2. Run `dotnet restore` and `dotnet test`.
3. Keep pull requests focused and explain the problem being solved.
4. Add tests for behavior changes and update docs/examples as needed.
5. Never commit credentials, production exports, personal data, or secrets.
6. Ensure build and tests pass before opening a pull request.

When reporting a bug, provide a minimal sanitized JSON example, expected behavior, actual behavior, and relevant output.
